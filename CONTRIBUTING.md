# Contributing

OpenScholar MCP is currently in planning. Contributions should preserve its legal-access-first and evidence-first design.

- Open an issue/discussion for material scope changes.
- Record architecture changes as ADRs in `docs/decisions`.
- Link provider claims to official documentation.
- Never add copied research PDFs, API secrets, or provider credentials.
- Add tests, migration notes, contract docs, and policy review with implementation changes.

No contributor licence or code-of-conduct policy has been selected yet; decide those before accepting external contributions.
